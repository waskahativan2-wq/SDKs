# SDKs

## Firebase Admin SDKs

Firebase Admin SDKs provide server-side access to Firebase services. The official SDKs are:

- [Node.js](https://firebase.google.com/docs/admin/setup#node.js) ([source](https://github.com/firebase/firebase-admin-node))
- [Java](https://firebase.google.com/docs/admin/setup#java) ([source](https://github.com/firebase/firebase-admin-java))
- [Python](https://firebase.google.com/docs/admin/setup#python) ([source](https://github.com/firebase/firebase-admin-python))
- [Go](https://firebase.google.com/docs/admin/setup#go) ([source](https://github.com/firebase/firebase-admin-go))
